# Changelog

## 2.0.0 (2026-11-12)
- A new, independently written engine: eight transparent checks, equal weight, EN / PT-BR / FR, running in the browser with no dependencies.
- Simplified product: the checklist, an improved prompt, a security scan, the CLI, and `/api/analyze`.
- Removed: the 1.x analysis engine and its scoring profiles, the hosted-AI judge, the benchmark runner, execution readiness, the coverage graph, code alignment, the savings model and artifact signing.
- The 1.x releases remain in the git history and are no longer maintained.
