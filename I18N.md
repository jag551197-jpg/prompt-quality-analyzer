# Internationalization

Complete UI localization: 🇺🇸 English (`en-US`), 🇧🇷 Português (Brasil) (`pt-BR`), 🇫🇷 Français (`fr-FR`). Static labels, options, helper/privacy text and dynamically inserted counters are localized live. Gemini output follows the selected locale using professional local technical terminology. Stable machine reason codes/model/version identifiers remain untranslated for auditability. A PT-BR coverage audit blocks releases containing new untranslated static UI labels.
