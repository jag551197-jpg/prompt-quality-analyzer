# PQA Savings Model v1.0

Community shows an **Estimated Efficiency Wallet**. It is not a billing statement.

The model estimates:
- prompt/input tokens;
- expected output tokens by task class;
- expected corrective attempts from PQA score and risk;
- projected retry reduction after a recommended instruction;
- token savings and direct AI cost avoidance.

Token count uses a transparent heuristic of approximately 4 characters per token. Provider prices are a configurable planning profile. Wallet data stays in the browser and can be reset.
